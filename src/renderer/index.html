    ⚡ SSH Remote Studio

    通过 SSH 打开远程计算机上的任意文件夹，浏览与编辑文件，并管理端口转发。

    • 📁 在左侧新建一个连接（支持密码 / 私钥 / Agent 认证）
    • 📝 连接后浏览远程目录树，打开并保存文件
    • 🔌 在「端口转发」中添加本地 (-L)、远程 (-R) 或动态 SOCKS (-D) 转发
      ●

      📂 从左侧目录树选择一个文件以打开

      支持查看与编辑文本文件，Ctrl+S 保存到远程

      转发端口以在本地访问正在运行的服务
      类型转发本地地址状态连接数流量

      没有转发的端口。
