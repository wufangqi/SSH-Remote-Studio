    SSH Remote Studio

    通过 SSH 打开远程计算机上的任意文件夹，浏览与编辑文件，并管理端口转发。

    远程文件

    懒加载目录树，打开并编辑文本文件，Ctrl+S 直接保存回远程。

    端口转发

    本地 -L、远程 -R、动态 SOCKS -D 三种隧道，实时状态与流量。

    安全连接

    密码 / 私钥 / Agent 认证，TOFU 主机密钥校验，凭据加密存储。
